# 百ます計算ジェネレーター

百ます計算を生成し、印刷できるサービスです。<br>このツールを使用することで、簡単に計算練習用のシートを作成できます。

## 特徴

- **カスタマイズ可能**: 足し算、引き算、掛け算を選択可能。
- **ランダム生成**: 毎回異なる問題を生成。
- **印刷対応**: A4サイズでの印刷に対応しています。

## 使用方法

1. サービスを開きます。
2. 計算の種類を選択します。
3. 問題の難易度や範囲を設定します。
4. 印刷ボタンから、印刷して使用してください。

## 必要条件

- 最新のウェブブラウザ（Google Chrome, Firefox, Edgeなど）
